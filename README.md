# Personal GitHub Pages blog

Small personal website for myself, developed on Jekyll and hosted on Github Pages.

I run a combined setup of Jekyll + GitHub Pages for the website management, and Obsidian for creating posts and webapges. My personal Obsidian app contains both the Git plugin as well as the Templater. The Git plugin let's me commit to the github remote repo from within Obsidian, and the Templater allows all new .md files created inside of my Obsidian Vault to be created with the template that Jekyll expects from .md files in /_posts. More details on how I got this interesting script working is available on the website itself, alongside other commentaries and reflections from other projects :D
